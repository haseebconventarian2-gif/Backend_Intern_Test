Backend Fundamentals

 (a) What is backend development and what role does it play in a web or mobile application?

 Answer: Backend Development is basically the Server Side Component of an application. It oversees the logic, authentication,api connenctions and communication between the frontend and the database. In Web and Mobile Applications , backend handles all the work/functionalities that are happening behinf the scenes

  (b) What is an API? Give one practical example.

  Answer: API is short for Application Programming Interface. It allows different application to communicate with one another.

  For example, an online shopping application can use a payment API to send payment details to a payment  service and receive confirmation about whether the payment was successful.


(c) What is a REST API, and what are GET, POST, PUT/PATCH, and DELETE used for?

Answer: REST API is an API that follows REST principles and communicates over HTTP.

Get is used for Data retrevial.
Post is used to create new data
Put is used to update existing data
Patch is used to partially update an existing data
Delete is used to remove data

(d) Explain the difference between authentication and authorization?

Answer: Authentication is mainly used for checking who the user is, whereas authorization checks what the user is allowed to do.

(e) What is JSON and why is it commonly used for API communication?

Answer: JSON is a light weight format used for storing and exchanging data. It is generally used in API communication because it is easier for humans to read and for programming langaues to process.
